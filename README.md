## Run locally
1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

No build tools or package installation are required.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `nourish-bloom-pharmacy`.
2. Upload all project files and folders, keeping the structure intact.
3. In the repository, open **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose the `main` branch and `/ (root)` folder, then save.
6. Wait for GitHub Pages to publish the site.

## Customisation notes
- Edit business details and page content in `index.html`.
- Change colours, typography, spacing and responsive layouts in `style.css`.
- Edit the mobile navigation and small interactions in `script.js`.
- Replace the remote Unsplash image URLs with approved business photography when available.
- Confirm all business details, service descriptions, contact information and any regulatory wording with the pharmacy before publishing.

## Important implementation notes
- This is a front-end portfolio concept. It does not process payments, store patient information, issue prescriptions or provide medical advice.
- WhatsApp links open a conversation with the supplied business number. Appointment/enquiry links are contact shortcuts, not a live booking system.
- Product availability, delivery coverage, opening hours, professional credentials and service terms have not been invented; add them only after confirmation by the business.
- Images are loaded from Unsplash and therefore require an internet connection. Replace them with licensed/approved local assets before a production handover if preferred.
